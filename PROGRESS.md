# Progress Rules

Навык считается освоенным не тогда, когда материал был прочитан, а когда выполнены четыре условия:

* [ ] Understand — понимаю концепцию.
* [ ] Implement — могу реализовать её самостоятельно.
* [ ] Explain — могу объяснить её другому человеку.
* [ ] Apply — могу применить её в реальной задаче.

Если выполнено только чтение или просмотр материала — навык остаётся незакрытым.
